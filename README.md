# InSport App — Android Sports Management App

A real-time Android application that helps supervisors monitor 
and coordinate sports activities and events efficiently.

## Features
- Real-time sports activity monitoring for supervisors
- Live push notifications for event updates
- Alert system for participants and coordinators
- Multi-event coordination from a single dashboard

## Tech Stack
- Android (Java)
- REST APIs
- Push Notifications
- MySQL Database
- Android Studio

## How It Works
1. Supervisors log in and view all active sports events
2. Real-time updates are pushed to participants via notifications
3. Coordinators can send alerts and event changes instantly
4. All activities are tracked and logged for review

## Results
- Served 100+ participants and supervisors across multiple events
- Real-time notifications reduced communication delays significantly
